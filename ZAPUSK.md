# Как запустить у себя

Система запускается на вашем компьютере и работает без интернета. Данные никуда
не уходят: база — обычный файл в папке `var` рядом с проектом.

Выберите **один** способ из трёх.

---

## Способ 1. Docker — проще всего, ничего не надо настраивать

Подходит, если не хочется разбираться с Python и распознаванием текста: в образе
уже всё есть, включая русский OCR.

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/)
   и запустите его (в трее должен появиться значок кита).
2. Откройте терминал в папке проекта и выполните:

```bash
docker compose run --rm app python -m app.seed --reset   # демо-данные, один раз
docker compose up
```

3. Откройте **http://localhost:8000**

Остановить — `Ctrl+C` в терминале. Запустить снова — `docker compose up`.
Обращения и вложения сохраняются в папке `var` и переживают перезапуск.

---

## Способ 2. Windows без Docker

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/).
   **Обязательно** отметьте галочку «Add python.exe to PATH» на первом экране
   установщика — без неё ничего не заработает.
2. Для распознавания фотографий и сканов установите Tesseract:

```powershell
winget install UB-Mannheim.TesseractOCR
```

   При установке в списке «Additional language data» отметьте **Russian**.
   Шаг необязательный: без него не будут распознаваться фото и сканы, всё
   остальное — реестр, сроки, флажки, PDF с текстовым слоем, DOCX — работает.

3. **Дважды щёлкните файл `RUN.bat`** в папке проекта.

   Распакуйте проект в путь без русских букв и пробелов — например `C:\dpo`.
   Кириллица в пути иногда ломает установку библиотек.

Откроется чёрное окно, установятся зависимости (первый раз — несколько минут),
затем сам откроется браузер. Демонстрационные данные подставятся автоматически
только при самом первом запуске — дальше ваши данные не перезаписываются.

Окно закрывать нельзя: сервер работает, пока оно открыто. Остановить — `Ctrl+C`.

Если предпочитаете командную строку, откройте PowerShell в папке проекта
(правой кнопкой по папке → «Открыть в терминале») и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 -Seed
```

Следующие запуски — то же самое без `-Seed`.

## Способ 3. macOS или Linux без Docker

```bash
# macOS
brew install tesseract tesseract-lang poppler

# Ubuntu / Debian
sudo apt-get install -y tesseract-ocr tesseract-ocr-rus poppler-utils
```

Затем в папке проекта:

```bash
SEED=1 ./run.sh
```

Откройте **http://127.0.0.1:8000**. Следующие запуски — `./run.sh`.

## Что дальше

**Убрать демонстрационные данные.** Они вымышленные — «Ромашка» и «Василёк».
Удалите папку `var` и запустите заново без `SEED` / `-Seed`: база будет пустой.

**Внести свои справочники.** Раздел «Справочники» в интерфейсе:
- **Юридические лица** — укажите синонимы для распознавания в тексте
  (название, латиницей, ИНН). По ним обращение привязывается к оператору.
- **Почтовые ящики** — адрес и тематика (`privacy`, `dpo`, `hr`, `support`).
  Тематика подсказывает системе, чего ждать от письма.
- **Сервисы и процессы** — ключевые слова. Здесь самая большая отдача:
  по ним обращение привязывается к бизнес-процессу.

**Загрузить типовые ответы.** Раздел «Типовые ответы» → «Загрузить файлы».
Берите свои реальные DOCX. Плейсхолдеры система найдёт сама.

⚠️ Внимательно со сроками в шаблонах: `{{СРОК ОТВЕТА}}` и
`{{СРОК ПРЕКРАЩЕНИЯ ОБРАБОТКИ}}` — **разные даты**.

**Настроить ежедневный пересчёт.** Срочность зависит от текущей даты, поэтому
раз в сутки нужно её пересчитать.

Linux / macOS (`crontab -e`):

```cron
5 6 * * * curl -fsS -X POST http://127.0.0.1:8000/api/maintenance/recalculate
```

Windows — «Планировщик заданий», ежедневно в 6:05, действие:

```
powershell -Command "Invoke-RestMethod -Method Post http://127.0.0.1:8000/api/maintenance/recalculate"
```

## Если что-то пошло не так

**«No suitable Python runtime found» или «Не найден подходящий Python»** —
Python не установлен. В системе есть только лаунчер `py`, но самого
интерпретатора за ним нет. Поставьте Python с
[python.org/downloads](https://www.python.org/downloads/), обязательно отметив
галочку «Add python.exe to PATH» на первом экране установщика, и запустите
`RUN.bat` заново.

**«python не является внутренней или внешней командой»** — Python установлен без
галочки «Add python.exe to PATH». Переустановите, отметив её.

**«port already in use» / «address already in use»** — система уже запущена в
другом окне. Либо закройте его, либо запустите на другом порту:
`./run.sh` с `PORT=8001`, `.\run.ps1 -Port 8001`.

**Фото и сканы не распознаются** — не установлен Tesseract или нет русского
языка. Проверьте в интерфейсе слева внизу блок «Состояние системы»: там прямо
написано, что доступно, а что нет.

**Страница не открывается** — убедитесь, что в терминале написано
`Uvicorn running on http://127.0.0.1:8000` и окно не закрыто. Сервер работает,
пока открыто окно терминала.
